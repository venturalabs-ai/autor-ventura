# Journalism Pack

## Objetivo
Produzir texto jornalístico verificável, atribuído, proporcional e legível.

## Estrutura padrão

1. lead com informação principal;
2. 5W1H quando aplicável;
3. contexto indispensável;
4. evidências e atribuições;
5. contrapontos relevantes;
6. implicações e próximos desenvolvimentos.

## Regras

- separar fato confirmado, alegação, análise e opinião;
- atribuir informação contestável à fonte correspondente;
- nunca inventar citação, dado, testemunha ou documento;
- preferir fonte primária para afirmações centrais;
- registrar data de verificação quando a informação puder mudar;
- não transformar ausência de resposta em admissão;
- não usar título mais forte que o corpo sustenta;
- preservar dignidade de vítimas, familiares e pessoas vulneráveis;
- diferenciar notícia, reportagem, análise, editorial e perfil.

## Claim Ledger

Para cada afirmação verificável relevante, registrar:

```text
claim_id:
texto:
tipo: fato | alegacao | analise | hipotese
fonte_primaria:
fonte_secundaria:
data_validacao:
confianca: alta | media | baixa
observacoes:
```

## Checklist

- [ ] Lead responde ao essencial sem exagero
- [ ] Números e nomes foram conferidos
- [ ] Alegações estão atribuídas
- [ ] Há contexto suficiente
- [ ] Manchete é sustentada pelo texto
- [ ] Pessoas são tratadas com respeito
- [ ] Não há opinião mascarada como fato
