# Publication Packs — Autor Ventura v3

Publication Packs traduzem intenção em regras editoriais específicas. O roteador deve selecionar um pack antes da redação.

## Contrato de decisão

Todo pedido deve ser normalizado em sete campos:

1. **speaker** — quem fala/assina;
2. **audience** — para quem;
3. **purpose** — informar, explicar, convencer, registrar, ensinar ou emocionar;
4. **medium** — jornal, TV, revista, livro, edital, trabalho acadêmico, simpósio ou cerimônia;
5. **evidence_level** — baixo, moderado, alto ou crítico;
6. **emotion_level** — contido, equilibrado, expressivo ou íntimo;
7. **limits** — restrições factuais, éticas, legais, acadêmicas, de privacidade, duração e formato.

## Packs

| Pack | Estrutura dominante | Evidência | Regra crítica |
|---|---|---:|---|
| newspaper | lead + 5W1H + contexto + atribuição | alta | opinião nunca vira fato |
| broadcast | texto falado + blocos temporais + sonora/GC | alta | escrever para o ouvido |
| magazine | abertura + cena + contexto + aprofundamento | moderada/alta | narrativa não pode sacrificar precisão |
| books | arquitetura longa + continuidade + memória | variável | preservar voz, arco e coerência |
| edital | requisito → evidência → resposta → risco | crítica | nunca afirmar requisito atendido sem prova |
| academic | pergunta → método → evidência → discussão | crítica | nenhuma referência, dado ou resultado inventado |
| symposium | resumo → argumento → evidência → apresentação | crítica | adaptar conteúdo ao tempo e à audiência |
| ceremonial | memória real → significado → promessa/mensagem | baixa/moderada | intimidade, consentimento e respeito |

## Seleção

Se houver múltiplos meios, o sistema cria uma peça-mãe factual e deriva versões por canal sem alterar fatos centrais. Exemplo: relatório técnico → release → matéria → roteiro de TV.

## Regra de saída

Antes do texto final, o sistema deve conseguir responder internamente:

`quem fala → para quem → por quê → em qual meio → com quais evidências → com qual emoção → dentro de quais limites`
