# Editais Pack

## Objetivo
Converter um edital em uma matriz verificável de requisitos, evidências, riscos e respostas.

## Fluxo

`requisito → evidência disponível → documento comprobatório → resposta proposta → risco`

## Matriz mínima

| Campo | Conteúdo |
|---|---|
| item | número/seção do edital |
| requisito | exigência literal resumida |
| tipo | técnico, jurídico, econômico, documental, prazo |
| evidência | documento/fato que comprova |
| status | atendido, parcial, pendente, não atendido |
| risco | baixo, médio, alto, crítico |
| ação | próxima providência |

## Regras

- nunca declarar requisito atendido sem evidência;
- preservar redação e numeração do edital para rastreabilidade;
- separar interpretação de exigência literal;
- destacar prazos, anexos, assinaturas, certidões e formatos obrigatórios;
- apontar inconsistências e lacunas sem inventar documentos;
- em dúvida jurídica/regulatória, sinalizar necessidade de revisão especializada.
